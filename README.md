# Simulateur d’API REST

Prototype pédagogique en HTML, CSS et JavaScript. La page illustre des parcours de formulaire et des exemples de réponses JSON.

## Périmètre

- Les formulaires et la session sont simulés dans le navigateur.
- Les réponses sont des exemples locaux.
- Le jeton affiché est un objet de démonstration, sans signature.
- Aucune API, base de données ni authentification réelle n’est fournie.
- Ne saisissez aucun vrai mot de passe ni donnée personnelle.

## Lancer localement

Ouvrez `index.html` dans un navigateur. Le projet n’a pas de dépendance à installer.

## Vérifier

```sh
node --check app.js
```

La publication GitHub Pages sera activée après revue et fusion de la branche dédiée.
